# 🚀 셀러 콕핏 (Seller Cockpit)
> **1인 온라인 쇼핑몰 운영자를 위한 단일 화면(Single Page) 통합 관제 대시보드**

`index.html` 파일 하나로 브라우저(Chrome, Edge, Safari, Whale 등)에서 즉시 실행되는 초경량 고성능 운영 대시보드입니다. 별도의 서버 설치나 복잡한 설정 없이 더블 클릭으로 바로 사용할 수 있습니다.

---

## 🌟 주요 기능 안내

### 1. 3초 퀵 현황 & 상단 KPI 카드
- **이번 달 총 매출**: 이번 달 발생한 총 매출액 및 주문 건수 실시간 집계
- **이번 달 순이익**: 매입가 차감 실질 순마진액
- **평균 마진율 (%)**: 비즈니스 수익성 시각화 바 게이지
- **⚠️ 오늘 발주 필요 건수**: 아침에 가장 먼저 처리해야 할 '결제완료' 상태 주문 수량 강조 표시

### 2. 멀티채널 판매자 센터 & 소싱처 퀵 런처
- 쿠팡 윙 (WING), 롯데온 스토어센터, 큐텐 재팬 QSM, 테무 셀러센터, 도매매/도매꾹, 1688/타오바오 바로가기 원클릭 새 탭 버튼

### 3. 3초 퀵 주문 & 판매 기록 (이중 입력 제거)
- 일자, 채널(쿠팡/롯데온/큐텐/테무/도매매/기타), 상품명, 고객명, 연락처, 매입가, 판매가, 수량, 배송상태, CS메모 입력
- 매입가/판매가 입력 즉시 **순이익과 마진율이 실시간으로 자동 계산**
- 키보드 `Enter` 키로 빠른 연속 등록 가능

### 4. 주문 & 배송 관리 리스트
- 고객명, 상품명, 전화번호 실시간 검색 필터
- 채널별 (쿠팡, 롯데온, 큐텐, 테무, 도매매 등) 탭 필터
- 배송 상태 (🟡 발주필요 $\rightarrow$ 🚚 배송중 $\rightarrow$ 🟢 완료 $\rightarrow$ 🔴 취소·환급) 드롭다운으로 즉시 상태 변경
- **엑셀(CSV) 다운로드**: 한국어 엑셀에서 글자가 깨지지 않도록 UTF-8 BOM 완벽 지원

### 5. 소싱 & 상품 파이프라인
- 발굴 상품명, 소싱 국가 (중국, 일본, 국내, 미국 등), 소싱처 URL, 예상 매입가, 진행 상태 (아이디어 ⚪, 소싱중 🟡, 판매중 🟢) 관리
- **판매 등록으로 가져오기 버튼**: '판매중' 상품의 버튼 클릭 시 상단 주문 입력 폼으로 상품명과 매입가가 자동 복사되어 주문 입력 속도 극대화

### 6. 오늘의 업무 체크리스트 & 마케팅 메모
- 아침에 처리할 발주, CS 문의, 상품 등록 등의 To-Do 체크리스트
- 단가 계산, 환율, 블로그/SNS 마케팅 키워드 자동 저장 스크래치패드 메모장

### 7. 데이터 안전 백업 & 복원
- 브라우저 LocalStorage에 모든 데이터가 자동으로 안전하게 영구 저장됩니다.
- 우측 상단의 **[데이터 백업]** 버튼으로 전체 데이터를 JSON 파일로 다운로드하여 영구 보관할 수 있습니다.
- **[복원]** 버튼으로 언제든지 백업된 JSON 파일을 불러올 수 있습니다.
- **[샘플 데이터]** 버튼을 누르면 즉시 미리 준비된 실제 예시 데이터로 대시보드를 체험할 수 있습니다.

## 💻 실행 방법
1. 탐색기에서 [index.html](file:///c:/gb_file/1027_001/index.html) 파일을 더블 클릭하여 크롬이나 엣지 등 선호하는 브라우저로 엽니다.
2. 우측 상단의 **[샘플 데이터]**를 클릭해 보시면 즉시 작동 방식을 한눈에 파악하실 수 있습니다.
